**Helm beats "best rate now" by 11.56 points** of total return (-7.62% against -19.18%).
**Helm loses to "all lending" by 7.79 points** (-7.62% against 0.16%). This is stated in the README and the dashboard, not hidden: the evaluation window is a falling market, and staying in lending is the safe thing to do in it.
**Helm loses to "static 50/50" by 1.95 points** (-7.62% against -5.68%). The model pays $2,658.44 of rebalance cost over 266 trades for that.
